Hey r/LocalLLaMA!

This repository contains an open-source multi-agent orchestration engine with selected audit and governance controls. It does not eliminate execution drift; review outputs and verify each deployment's controls.

### Why we built it:
Existing agent frameworks (LangChain, AutoGen, CrewAI) rely heavily on single-threaded Python event loops and unverified state transitions. Over multi-step workflows, compound error rates degrade output quality rapidly.

### Core Features:
- 🦀 **Rust Backend (`server-rs`)**: Axum and Tokio power the engine; route latency and memory use depend on build, configuration, workload, and hardware.
- 🔐 **Audit and governance controls**: Review the documented event coverage and deployment configuration; do not assume every prompt or action is covered or that tampering automatically halts all operations.
- 🐸 **Planned SMB Digital Twin**: Company-scoped execution and storage are pending; use synthetic previews only.
- 🏪 **External template portal**: Templates are starting points and require review before use.
- 🕸️ **Graph Intelligence UI**: The repository includes a visualizer for code and knowledge graph data.
- 🧪 **Verification**: Test counts change with the checkout; use current CI and local verification results.

### Tech Stack:
- **Backend**: Rust, Axum, SQLx, SQLite, Tokio
- **Frontend**: React 19, TypeScript, TailwindCSS, D3 Force Graph
- **LLM Backends**: Local Ollama / Gemma 4 / Llama 3 + Cloud APIs (Gemini, Claude, OpenAI)
