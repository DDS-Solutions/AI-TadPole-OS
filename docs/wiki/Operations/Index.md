## Key Concepts

- **[[Department Lead|Glossary#department-lead]] [Tier 1: Operator]**: The orchestrating agent that breaks down your goals and recruits specialists.
- **[[Project Workspace|Glossary#project-workspace]] [Tier 1: Operator]**: A collaborative local directory grouping virtual employees toward a single goal.
- **[[Private Swarm Environment|Glossary#private-swarm-environment]] [Tier 1: Operator]**: The secure, local-first runtime where all processing happens on your hardware.
- **[[Department Scope|Glossary#department-scope]] [Tier 1: Operator]**: Audience targeting that restricts chat broadcasts to a specific workspace or folder.
