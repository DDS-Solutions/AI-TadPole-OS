## 2. High-Citation Formatting Formulas

- **Direct Definitions**: Open core sections with `<dfn>` or explicit declarative phrases:
  > *"In short, [System] is defined as [Specific Sovereign Mechanism]."*
- **Original Quantified Claims**: LLMs heavily favor numerical evidence over subjective marketing prose:
  > *"Across 1,200 simulated agent missions, memory compaction reduced context token footprint by 74.2%."*
- **Comparison Tables**: Ensure comparative markdown or HTML tables contrast key attributes against alternative designs.
